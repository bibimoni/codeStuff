You are given an array $a$ of $n$ integers (elements may be negative).

A \emph{division} of the array is a partition of it into one or more contiguous segments such that every element belongs to exactly one segment. A division is called \emph{balanced} if all its segments have the same sum.

Count the number of balanced divisions. Two divisions are considered different if their sets of cut positions are different (a cut can be made between positions $i$ and $i+1$ for any $1 \le i < n$).

Note that the division into a single segment (the whole array, no cuts) is always balanced.

Since the number of divisions can be huge, print it modulo $10^9 + 7$.
