The first line contains a single integer $t$ ($1 \le t \le 100$) --- the number of test cases.

The first line of each test case contains a single integer $m$ ($1 \le m \le 100$) --- the number of lines.

Each of the next $m$ lines contains one string $s$ ($1 \le |s| \le 10\,000$). Every string consists only of lowercase Latin letters and spaces, and neither starts nor ends with a space. Do note the spaces: read whole lines.

It is guaranteed that the total length of all strings over all test cases does not exceed $10^6$.
