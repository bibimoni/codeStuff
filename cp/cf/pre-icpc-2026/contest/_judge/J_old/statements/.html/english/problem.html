Equal Sum Segments
time limit per test
2 seconds
memory limit per test
256 megabytes
input
standard input
output
standard output

You are given an array $$$a$$$ of $$$n$$$ integers (elements may be negative).

A division of the array is a partition of it into one or more contiguous segments such that every element belongs to exactly one segment. A division is called balanced if all its segments have the same sum.

Count the number of balanced divisions. Two divisions are considered different if their sets of cut positions are different (a cut can be made between positions $$$i$$$ and $$$i+1$$$ for any $$$1 \le i \lt n$$$).

Note that the division into a single segment (the whole array, no cuts) is always balanced.

Since the number of divisions can be huge, print it modulo $$$10^9 + 7$$$.

Input

The first line contains a single integer $$$t$$$ ($$$1 \le t \le 10^5$$$) — the number of test cases.

The first line of each test case contains a single integer $$$n$$$ ($$$1 \le n \le 10^5$$$) — the size of the array.

The second line of each test case contains $$$n$$$ integers $$$a_1, a_2, \ldots, a_n$$$ ($$$-10^9 \le a_i \le 10^9$$$) — the elements of the array.

It is guaranteed that the sum of $$$n$$$ over all test cases does not exceed $$$10^5$$$.

Output

For each test case, print a single integer — the number of balanced divisions of the array, modulo $$$10^9 + 7$$$.

Example

Input
6
4
1 2 1 2
4
1 -1 1 -1
2
1 1
1
5
2
-1 -1
6
1 2 3 0 2 4
Output
2
2
2
1
2
3

Note

The example contains six test cases.

  • $$$a = [1, 2, 1, 2]$$$, total sum $$$6$$$. Balanced divisions: the whole array (one segment of sum $$$6$$$), and $$$[1, 2]\;[1, 2]$$$ (two segments of sum $$$3$$$). Three segments of sum $$$2$$$ would require a prefix of sum $$$2$$$, which does not exist. Answer: $$$2$$$.
  • $$$a = [1, -1, 1, -1]$$$, total sum $$$0$$$, so every segment must sum to $$$0$$$. The only position $$$i \lt n$$$ with prefix sum $$$0$$$ is $$$i = 2$$$, and we may either cut there or not. Answer: $$$2$$$.
  • $$$a = [1, 1]$$$: $$$[1, 1]$$$ or $$$[1]\;[1]$$$. Answer: $$$2$$$.
  • $$$a = [5]$$$: only the single segment. Answer: $$$1$$$.
  • $$$a = [-1, -1]$$$: same as the third case with a negative total. Answer: $$$2$$$.
  • $$$a = [1, 2, 3, 0, 2, 4]$$$, total sum $$$12$$$. With $$$k = 2$$$ segments (sum $$$6$$$ each) the cut can be made after index $$$3$$$ or after index $$$4$$$, since both prefix sums equal $$$6$$$ — that gives $$$2$$$ divisions. No $$$k \in \{3, 4, 6\}$$$ works (e.g. for $$$k = 3$$$ a prefix of sum $$$4$$$ is required but absent). Together with the single-segment division, the answer is $$$3$$$.
