Multiplication Game
time limit per test
1 second
memory limit per test
256 megabytes
input
standard input
output
standard output

Twin sisters often play games involving numbers together. First, they agree on a positive integer $$$n$$$. Then, they start playing with the initial value $$$p = 1$$$. The two players take turns, with the younger sister always going first. On their turn, the current player multiplies $$$p$$$ by any integer $$$k$$$ such that $$$2 \le k \le 9$$$. The winner is the first person to make $$$p \ge n$$$.

Determine which player will win if both play optimally.

Input

The first line contains an integer $$$T$$$ ($$$1 \le T \le 10^4$$$) — the number of test cases.

Each of the following $$$T$$$ lines contains a single integer $$$n$$$ ($$$1 \le n \le 10^9$$$).

Output

For each test case, print a single line containing:

  • La premiere joueuse gagne. — if the first player (younger sister) wins.
  • La deuxieme joueuse gagne. — if the second player (older sister) wins.

Example

Input
3
9
18
27
Output
La premiere joueuse gagne.
La deuxieme joueuse gagne.
La premiere joueuse gagne.
