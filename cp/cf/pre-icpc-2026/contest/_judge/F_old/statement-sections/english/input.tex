The first line contains a single integer $n$ ($7 \le n \le 100$) --- the number of men in the park.

Each of the next $n$ lines contains a string $S$ and an integer $H$ ($1 \le |S| \le 10$, $1 \le H \le 1000$) --- the name of a man, consisting of English letters, and his height.

It is guaranteed that exactly seven of the men have the same height, and that no other man has that height, so the seven dwarfs can be uniquely identified.
