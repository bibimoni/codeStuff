The Hidden Cave
time limit per test
2 seconds
memory limit per test
256 megabytes
input
standard input
output
standard output

Minh discovers a mysterious cave system consisting of many interconnected chambers.

The cave system forms a complete binary tree. The entrance of the cave is the root of the tree, and Minh initially stands at the entrance.

Each chamber may have a passage leading to its left child and a passage leading to its right child. Every chamber except the entrance also has a passage leading back to its parent.

A complete binary tree is a binary tree in which every level, except possibly the last, is completely filled, and all nodes on the last level are as far to the left as possible.

Minh does not know the structure of the cave or the total number of chambers.

Your task is to determine the total number of chambers in the cave by moving through it using the allowed queries.

For each test case, the number of chambers $$$N$$$ satisfies

$$$$$$1 \le N \le 10^{18}.$$$$$$

Input

The first line contains an integer $$$T$$$ ($$$1 \le T \le 20$$$), the number of test cases.

For each test case, the number of chambers $$$N$$$ is hidden and is not given directly to your program. It can only be determined through interaction.

Interaction

The interactor first prints an integer $$$T$$$, the number of test cases.

For each test case, Minh initially stands at the root of the tree.

To move through the cave, you may print one of the following queries:

  • $$$\texttt{? L}$$$ — attempt to move from the current chamber to its left child;
  • $$$\texttt{? R}$$$ — attempt to move from the current chamber to its right child;
  • $$$\texttt{? B}$$$ — attempt to move from the current chamber to its parent.

After each query, the interactor prints an integer:

  • $$$1$$$ if the requested move is possible. In this case, Minh moves to the corresponding chamber;
  • $$$0$$$ if the requested move is impossible. In this case, Minh remains in the current chamber.

In particular, the query $$$\texttt{? B}$$$ returns $$$0$$$ when Minh is currently at the root.

You may perform at most $$$8000$$$ queries for each test case.

When you have determined the total number of chambers, print

$$$$$$\texttt{! N}$$$$$$

where $$$N$$$ is the total number of chambers in the current test case.

Printing the final answer does not count as a query.

If the answer is correct, the interaction proceeds to the next test case. Otherwise, your submission receives a Wrong Answer verdict.

After printing every query, do not forget to flush the output. You must also flush the output after printing the final answer.

Example

Input
1
1
0
1
Output
? R
? R
? L
! 6

Note

In the example, the hidden number of chambers is $$$6$$$.

The first query moves Minh to the right child of the root, which exists.

The second query attempts to move to its right child. The interactor returns $$$0$$$, so chamber $$$7$$$ does not exist and Minh remains at chamber $$$3$$$.

The third query moves to the left child of chamber $$$3$$$. The interactor returns $$$1$$$, so chamber $$$6$$$ exists.

Since the tree is complete, chamber $$$6$$$ exists while chamber $$$7$$$ does not, therefore the total number of chambers is $$$6$$$.
