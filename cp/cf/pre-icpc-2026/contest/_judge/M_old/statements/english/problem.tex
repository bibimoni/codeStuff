\begin{problem}{K-th Inversion Permutation}{standard input}{standard output}{2 seconds}{256 megabytes}

A permutation of length $n$ is an array containing each integer from $1$ to $n$ exactly once.
An inversion of a permutation $p$ is a pair of positions $(i,j)$ such that $i<j$ and $p_i>p_j$.

You are given integers $n$, $m$, and $k$. Among all permutations of length $n$ with exactly $m$ inversions, ordered lexicographically, find the $k$-th one.

Permutation $a$ is lexicographically smaller than permutation $b$ if, at the first position where they differ, $a$ contains a smaller value than $b$.
If fewer than $k$ such permutations exist, print $-1$.


\InputFile
The first line contains one integer $t$ ($1 \le t \le 300$), the number of test cases.

Each test case consists of one line containing three integers $n$, $m$, and $k$ ($1 \le n \le 300$, $0 \le m \le \frac{n(n-1)}{2}$, $1 \le k \le 10^{18}$).

It is guaranteed that the sum of $n$ over all test cases does not exceed $300$.


\OutputFile
For each test case, print the $k$-th lexicographically smallest permutation of length $n$ having exactly $m$ inversions.

If it does not exist, print $-1$ instead.


\Examples

\Note
In the first test case, the permutations with exactly one inversion are $(1,3,2)$ and $(2,1,3)$, in this order.

In the fourth test case, only one permutation has six inversions, so the second such permutation does not exist.


\end{problem}
