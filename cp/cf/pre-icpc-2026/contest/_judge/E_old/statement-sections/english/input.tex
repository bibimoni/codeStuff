The first line contains a single integer $n$ ($1 \le n \le 4000$) --- the number of modules.

Each of the next $n - 1$ lines contains three integers $u$, $v$, and $w$ ($1 \le u, v \le n$, $w \in \{0, 1, 2\}$) --- a relation of type $w$ between modules $u$ and $v$.

It is guaranteed that the relations form a weakly connected graph.
