The example's test cases admit these balanced divisions:

\begin{itemize}
\item test case 1: there are $2$ ways of splitting: $[1, 2, 1, 2]$ and $[1, 2 \mid 1, 2]$;
\item test case 2: $[1, -1, 1, -1]$ and $[1, -1 \mid 1, -1]$;
\item test case 3: $[1, 1]$ and $[1 \mid 1]$;
\item test case 4: $[5]$ only;
\item test case 5: $[-1, -1]$ and $[-1 \mid -1]$;
\item test case 6: $[1, 2, 3, 0, 2, 4]$; $[1, 2, 3 \mid 0, 2, 4]$; and $[1, 2, 3, 0 \mid 2, 4]$.
\end{itemize}
