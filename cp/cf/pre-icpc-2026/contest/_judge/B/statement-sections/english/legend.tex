You are given an undirected graph of $N$ vertices connected by $M$ edges. Each vertex is currently in one of two states: off ($0$) or on ($1$). Toggling a vertex $u$ flips the state of vertex $u$ and of all vertices directly connected to $u$ by an edge. You are given $Q$ independent queries, each providing the initial state of all $N$ vertices. For each query, find a set of vertices to toggle so that all $N$ vertices end up on ($1$), or determine that it is impossible.
