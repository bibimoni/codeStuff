The first line contains three integers $N$, $M$, and $Q$ ($1 \le N \le 3000$, $0 \le M \le 3000$, $1 \le Q \le 500$) --- the number of vertices, edges, and queries.

Each of the next $M$ lines contains two integers $u$ and $v$ ($1 \le u, v \le N$, $u \neq v$) --- an undirected edge between vertices $u$ and $v$. It is guaranteed that no edge appears twice.

Each of the next $Q$ lines contains a string of $N$ characters, each either \texttt{0} or \texttt{1}; the $i$-th character denotes the initial state of vertex $i$.
