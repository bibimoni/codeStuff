The first line contains one integer $t$ ($1 \le t \le 300$), the number of test cases.

Each test case consists of one line containing three integers $n$, $m$, and $k$ ($1 \le n \le 300$, $0 \le m \le \frac{n(n-1)}{2}$, $1 \le k \le 10^{18}$).

It is guaranteed that the sum of $n$ over all test cases does not exceed $300$.
