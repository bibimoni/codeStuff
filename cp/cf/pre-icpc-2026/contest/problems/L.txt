# Problem L — Luminous Coral Loop
Time limit: 4s per test | Memory limit: 256 MB

## Statement
The Coral Loop is a ring of $n$ tiny islands, numbered from $1$ to $n$ around the atoll. Causeway $i$ connects island $i$ with island $i+1$ (for $1 \le i \le n-1$), and causeway $n$ loops back from island $n$ to island $1$. Crossing causeway $i$ costs $a_i$ shells --- several causeways cross such gorgeous lagoons that the paddlers' cooperative pays \emph{you} a rebate to use them, so some $a_i$ are negative.

In the middle of the atoll floats the Ferry Nook, a seaplane dock. A flight between the Nook and island $i$ costs $b_i$ shells, promos and rebates included, so some $b_i$ are negative as well. All causeways and flights operate in both directions at the same price.

Lani runs the trip kiosk. By the Paddlers' Charter --- twice-paddled water is wasted daylight --- a valid route may visit each location (islands and the Nook) at most once. Over the season she logs $q$ events of three kinds:

\begin{itemize}
\item A traveler asks for the cheapest valid route from location $s$ to location $t$ ($s < t$);
\item Causeway $x$ is repriced: $a_x$ becomes $w$;
\item The flight between the Nook and island $x$ is repriced: $b_x$ becomes $w$.
\end{itemize}

After every traveler's question Lani must announce the best possible price. The season is long, so help her answer quickly.

## Input
The first line contains a single integer $t$ ($1 \le t \le 3 \cdot 10^5$) --- the number of test cases.

The first line of each test case contains two integers $n$ and $q$ ($2 \le n \le 3 \cdot 10^5$, $1 \le q \le 3 \cdot 10^5$) --- the number of islands in the Coral Loop and the number of logged events.

The second line contains $n$ integers $a_1, a_2, \ldots, a_n$ ($-10^9 \le a_i \le 10^9$) --- the causeway prices: causeway $i$ connects islands $i$ and $i \bmod n + 1$.

The third line contains $n$ integers $b_1, b_2, \ldots, b_n$ ($-10^9 \le b_i \le 10^9$) --- the prices of flights between island $i$ and the Nook.

Each of the next $q$ lines describes one event in one of the following formats:
\begin{itemize}
\item \texttt{1 s t} ($1 \le s < t \le n+1$, where location $n+1$ is the Nook) --- print the cheapest valid route from location $s$ to location $t$;
\item \texttt{2 x w} ($1 \le x \le n$, $-10^9 \le w \le 10^9$) --- set $a_x := w$;
\item \texttt{3 x w} ($1 \le x \le n$, $-10^9 \le w \le 10^9$) --- set $b_x := w$.
\end{itemize}

It is guaranteed that the sum of $n$ over all test cases does not exceed $3 \cdot 10^5$, and the sum of $q$ over all test cases does not exceed $3 \cdot 10^5$.

## Output
For every event of type $1$, print a single integer on its own line --- the minimum possible price of a route from $s$ to $t$ that visits no location twice. Prices may be negative: rebates can make the cooperative pay the traveler.

## Notes
From island $1$ to island $3$ there are three routes: paddling $1 \to 2 \to 3$ costs $4 - 2 = 2$, the direct causeway costs $5$, and flying via the Nook costs $3 + 1 = 4$, so the first answer is $2$. After causeway $2$ is repriced to $6$ the Nook route wins at $4$, and once the flight to island $1$ goes on promo ($b_1 := -4$) flying costs $-4 + 1 = -3$ --- the cooperative pays the traveler $3$ shells. The last query asks for island $1$ to the Nook: the direct flight at $-4$ cannot be beaten.

## Example 1 — input
```
1
3 6
4 -2 5
3 7 1
1 1 3
2 2 6
1 1 3
3 1 -4
1 1 3
1 1 4
```
## Example 1 — output
```
2
4
-3
-4
```
