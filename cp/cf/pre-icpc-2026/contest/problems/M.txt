# Problem M — Marshal's Parade
Time limit: 2s per test | Memory limit: 256 MB

## Statement
The court marshal must parade all $n$ knights of the realm in single file. Court etiquette numbers the knights $1$ to $n$ by seniority, so a lineup is a permutation of length $n$ --- an array containing each integer from $1$ to $n$ exactly once.

Whenever a knight with a larger seniority number marches ahead of a knight with a smaller number, the court gossips about an \emph{insubordination}. Formally, an insubordination of a lineup $p$ is a pair of positions $(i,j)$ such that $i<j$ and $p_i>p_j$.

The king has read every treatise on heraldry and fixed his mind on exactly $m$ insubordinations. Among all lineups of length $n$ with exactly $m$ insubordinations, ordered lexicographically, he demands the $k$-th one.

Lineup $a$ is lexicographically smaller than lineup $b$ if, at the first position where they differ, $a$ marches a knight with a smaller seniority number than $b$.
If fewer than $k$ such lineups exist, print $-1$.

## Input
The first line contains one integer $t$ ($1 \le t \le 300$), the number of test cases.

Each test case consists of one line containing three integers $n$, $m$, and $k$ ($1 \le n \le 300$, $0 \le m \le \frac{n(n-1)}{2}$, $1 \le k \le 10^{18}$).

It is guaranteed that the sum of $n$ over all test cases does not exceed $300$.

## Output
For each test case, print the $k$-th lexicographically smallest lineup of length $n$ having exactly $m$ insubordinations.

If it does not exist, print $-1$ instead.

## Notes
In the first test case, the lineups with exactly one insubordination are $(1,3,2)$ and $(2,1,3)$, in this order.

In the fourth test case, only one lineup has six insubordinations, so the second such lineup does not exist.

## Example 1 — input
```
4
3 1 1
3 1 2
4 0 1
4 6 2
```
## Example 1 — output
```
1 3 2
2 1 3
1 2 3 4
-1
```
