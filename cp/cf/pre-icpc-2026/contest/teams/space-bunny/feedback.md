# space-bunny — contest feedback (13/13 solved, rank 4/13, penalty 308, 1 WA total)

- A (suffix-array): easy-medium | solved | Answer is `1 + #{i : rk[p_i+1] > rk[p_{i+1}+1]}` (rk[n]=-1); two suffixes may share a first char only if their tails' ranks are increasing — and `-1` is provably unreachable since the greedy always builds a valid string.
- B (grid-reboot): medium | solved | Lights-out over GF(2): one forward elimination on `[A|I]` bitsets (keeping the transform T aligned to a word boundary), then per query `c = T·b`, a consistency check on the zero rows, and back-substitution; the judge sample space-separates the bit strings so each bit is read with `" %c"`.
- C (the-hidden-cave): medium | solved | Interactive complete binary tree = (height h, last-level count m). Binary-search h by walking all-`L` to the leftmost node of a level, then binary-search m via the binary digits of (pos-1) as the path; navigating via longest-common-prefix climbs keeps it at ~3600 of the 8000 allowed queries even for N=10^18 (validated against a local mock interactor).
- D (mulgame): easy-medium | solved | The losing set is a ladder `(hi, 2*hi]` with `hi *= 18` from 9; derived by turning the state into the ratio r = n/p, then confirmed against a brute-force DP over the 5194 seven-smooth values of p.
- E (scheduling): hard | solved | Each valid (permutation, orientation) pair is in bijection with a permutation respecting only the fixed edges, so the answer is the number of linear extensions of a tree poset: root the forest, split each node's children into before/after, `f[v] = gB·gA` (v's position is forced, so no extra binomial), components merged with a shuffle.
- F (snow-white): easy | solved | Print the names whose height is the modal height, in input order; 8 MB / 0.25 s is no obstacle at n ≤ 100.
- G (self-crossing-turtle): medium | solved | Segment pairs matter only when |i-j| ≥ 2, so perpendicular pairs are a sweep line over x (excluding index-distance 1) and parallel pairs are an interval-overlap scan grouped by x (verticals) / y (horizicals).
- H (rlu-cache-easy): easy-medium | solved | LRU is a doubly-linked list and the recency rank is `1 + #{live keys with a larger access timestamp}`, so a Fenwick tree over timestamps answers it in O(log n); the initial timestamp of key i must be i.
- I (coolant-loops): easy-medium | solved | Independent loops = E − V + C, and deletions are handled in reverse with a DSU (restore a tile: C += 1 − #distinct neighbour components); the connection needs *both* tiles to open toward each other.
- J (dp-math-hard): hard | solved | With total S = 0 every cut must sit at a zero prefix (2^z), otherwise each balanced split has a strand sum v dividing S, the cut positions are forced to the prefix values v,2v,…,(g−1)v, and the number of ways is a layer-by-layer chain DP modulo 1e9+7.
- K (zero-segment): easy-medium | solved | Two zero supports let you rake every mound between them to zero for free, so the answer is min over i<j with j−i+1 ≥ k of a_i+a_j = min over j of (a_j + prefix-min[j−k+1]).
- L (coral-loop): very-hard | solved | Minimum-weight *simple* path on a ring + hub: the path is two disjoint contiguous arcs through the hub (4 direction cases) or one of the 2 cycle arcs; on a doubled array with F=SS+b, G=b−SS, P1=min_{i<j}(F_i+G_j) a lazy segment tree answers all cases, with updates a_x hitting two suffixes and b_x hitting two points.
- M (dp-counting-med): medium | solved | Mahonian numbers f[n][m] with the prefix-sum recurrence, then greedily pick the k-th lexicographic by scanning candidates (the idx-th smallest costs idx inversions); my first submit was WA because the running DP sum overflowed int64 — fixed with `__int128`.

The judge was a genuinely useful oracle: every wrong verdict pointed at a specific bug class (overflow, off-by-one on the answer index, sign errors in a lazy tag), and because failed tries on unsolved problems were free I submitted as soon as a solution was structurally complete. The single most valuable habit was building a brute-force harness per problem before submitting — the linked-list eviction order in H, the GF(2) word alignment in B, the arc-direction case analysis in L and the Mahonian overflow in M were all caught locally in seconds instead of costing judge attempts. The problem set was well-graded: A/F/D/K were minutes of work while E/J/L each needed a genuinely new structural idea (bijection to linear extensions, chain-DP over forced prefix values, 4-case path decomposition on a doubled ring), and a couple of sheets (H, and the samples of H and L) had mangled example blocks that had to be distrusted in favour of brute force.
